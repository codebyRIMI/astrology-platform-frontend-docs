# Frontend Architecture (High-Level)

## Application Type
- Frontend-only Single Page Application (SPA)

## Architectural Principles
- Component-driven UI
- Domain-based page segregation
- Layout-centric routing
- Reusability and scalability

## Conceptual Folder Structure
- pages/
  - Home
  - Panchang
  - Calendar
  - Jyotish
  - Muhurat
  - Vrat
  - Numerology
  - Festival
  - Admin
- components/
  - Navbar
  - Sidebar
  - Layout wrappers
  - Shared UI elements

## Routing Strategy
- Centralized frontend routing
- Nested routes for complex UI flows
- Layout-based grouping for consistency

## Scalability Focus
- Easy frontend feature extension
- Clear separation of UI responsibilities
- Minimal coupling between components
